## Changes made

1. **release skill: merge order and a mergeable gate** (#37/#45). `mergeable` is checked
   before the bump; CONFLICTING goes back to dev without a bump. With more than one card in
   Ship, the oldest PR merges first. After a merge, every other Ship PR is checked and any
   that turned CONFLICTING is bounced in the same pass.
2. **qa and dev skills: screenshots inline** (#37, #38, #39; owner ask 3 Oct). `gh` 2.99
   added `--attach`, which uploads an image and rewrites a `![](local/path.png)` reference
   in the body to the hosted URL. QA posts its checklist with each visual item's screenshot
   embedded; dev does the same in the PR body. Local `gh` upgraded 2.92.0 to 2.102.0.
3. **dev skill: compile androidTest** (#38/#46). Any diff touching `app/src/androidTest` gets
   `./gradlew compileDebugAndroidTestKotlin`, and dev runs the named instrumented class on the
   emulator before opening the PR.
4. **reviewer skill and AGENTS.md: code review only** (owner decision, 3 Oct). The reviewer
   no longer checks out the branch or runs gradle, adb or the emulator; that was a second
   copy of dev's self-check and of QA's build, and it produced zero asks in seven passes.
   It now reviews scope both ways (acceptance items without a change, changes without an
   acceptance item), correctness by reading, tests as written, repo patterns, and evidence
   embedded in the PR body. QA remains the only build-and-run gate after dev.

5. **dev and EM skills, AGENTS.md: no PR cards on the board** (#45, #52; follow-up #53 after
   #51 merged). The `board.sh add <PR>` step is gone; the issue card is the only card. The
   owner deletes the twelve existing PR cards by hand.

Removed this pass: the reviewer's test run and worktree (change 4) and the PR-card step
(change 5). Four changes rather than
the usual cap of three because the owner asked for the fourth and it is a removal.
