## Changes made

1. **release skill: merge order and a mergeable gate** (#37/#45). `mergeable` is checked
   before the bump; CONFLICTING goes back to dev without a bump. With more than one card in
   Ship, the oldest PR merges first. After a merge, every other Ship PR is checked and any
   that turned CONFLICTING is bounced in the same pass.
2. **qa and dev skills: screenshots inline** (#37, #38, #39; owner ask 3 Oct). `gh` 2.99
   added `--attach`, which uploads an image and rewrites a `![](local/path.png)` reference
   in the body to the hosted URL. QA posts its checklist with each visual item's screenshot
   embedded; dev does the same in the PR body. Local `gh` upgraded 2.92.0 to 2.102.0.
3. **dev and reviewer skills: compile androidTest** (#38/#46). Any diff touching
   `app/src/androidTest` gets `./gradlew compileDebugAndroidTestKotlin` from both, and dev runs
   the named instrumented class on the emulator before opening the PR.

Nothing removed this pass: no step has run long enough to call it dead weight.
