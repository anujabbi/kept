# Weekly goals mockups

Mockups for the weekly goals feature (see the linked issue). One example week: "Exercise, 4 days a week", Sunday to Saturday.

| File | Screen |
|---|---|
| `1-weekly-goal-setup.png` | Setup: pick an activity and days per week |
| `2-notification.png` | Wednesday notification on the first must-do day |
| `3-lock-screen.png` | Weekly goal lock screen: "4 days left, 4 to go." |
| `4-home-weekly-card.png` | Home card: "Exercise · 1 of 4 this week", on track |

The `.html` files are the static sources (390 × 844, Daybreak tokens, Bricolage Grotesque). `gen.py` regenerates them. The PNGs are rendered from the HTML. These are design input, not a pixel spec. Where they differ from the issue, the issue wins.
